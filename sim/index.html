💡 How Synchronous Single-Port Memory Works

This module models an industry-standard Synchronous Single-Port Static RAM (SRAM):
WIDTH = 32-bit | DEPTH = 256 Words | ADDR_WIDTH = 8-bit

  • Clocked posedge Evaluation: All internal memory writes and output register updates occur strictly on the positive edge of clk.
  • Synchronous Active-High Reset: If rst == 1 at the rising clock edge, all 256 memory locations are cleared to zero and outputs are reset (rdata=0, ready=0).
  • VALID Handshake Protocol: The valid pin is an input driven by the requester. When valid == 1, the memory accepts the command and asserts ready <= 1 on the clock edge.

⚡ Verilog Nonblocking (`<=`) Assignment Semantics

In digital design, sequential logic uses nonblocking assignments (<=).

  • Sample-then-Update: At the rising clock edge, the Right-Hand Side (RHS) of all statements is evaluated simultaneously using values present before the edge, and registers are updated in the nonblocking event queue.
  • Synchronous Read Latency: During a read (rdata <= mem[addr]), rdata does NOT change when the address bus changes—it updates strictly after the clocked posedge transition.
  • Default Register Clear: Notice lines 20–21 in the Verilog code clear rdata <= 0; ready <= 0; by default. If valid == 0, rdata and ready remain 0.

🎯 Timing & Clock Cycle Diagram

Cycle sequence for a typical Write followed by Read:

  1. Cycle N-1 (Setup): Master sets ADDR=10, WDATA=0xDEADBEEF, WR_RD=1, VALID=1 before clock edge.
  2. Cycle N (posedge CLK): Memory writes mem[10] <= 0xDEADBEEF and drives ready <= 1.
  3. Cycle N (Setup for Read): Master sets ADDR=10, WR_RD=0, VALID=1.
  4. Cycle N+1 (posedge CLK): Memory reads rdata <= mem[10] (0xDEADBEEF) and drives ready <= 1.

🏆 VLSI / RTL Interview Q&A

  • Q: Is this memory synchronous or asynchronous read?
    A: Synchronous read. The read operation is inside the always @(posedge clk) block.
  • Q: What happens if `valid` is low during a write?
    A: No write occurs, memory retains its previous value, and ready is 0.
  • Q: How many address bits are needed for 256 words?
    A: $2^8 = 256$, so 8 bits are required (addr[7:0]).
